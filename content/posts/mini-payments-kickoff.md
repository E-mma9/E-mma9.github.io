On 15 October I created [mini-payments-api](https://github.com/E-mma9/mini-payments-api/tree/feature/mini-payments-api-skeleton). The README is the plan, written as preparation for an internship.

The plan is a payments API on Java and Spring Boot, a PostgreSQL database, a Dockerfile, and a CI/CD pipeline that deploys to my own Kubernetes cluster on the homelab. Monitoring would be Prometheus and Grafana.

That is the plan. The pipeline, the deploy onto the homelab cluster, and the monitoring are still plans. The posts after this one are the parts that are built.
